# Málaga Databricks User Group

A local community for anyone interested in Databricks, data engineering, and AI. We’ll share materials from our meetups, talks, and workshops here.

Our first meetup is planned for early 2027.

- [Join the official chapter](https://usergroups.databricks.com/malaga-databricks-user-group/) to get notified when we announce the date.
- [Message us on LinkedIn](https://www.linkedin.com/company/malaga-databricks-user-group/) if you’d like to give a talk or suggest a topic.
