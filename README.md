# Databricks User Group Málaga

Comunidad local de Databricks, ingeniería de datos e IA en Málaga. Aquí compartiremos los materiales de nuestros meetups, charlas y talleres.

El primer meetup está previsto para principios de 2027. Únete al capítulo para recibir el anuncio cuando se confirme la fecha.
